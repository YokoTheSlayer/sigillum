# Architecture decision records

Architecture decision records (ADRs) document decisions that are expensive to reverse or define a cross-component contract.

- Copy `0000-template.md` for a new decision.
- Use the next four-digit sequence number.
- Keep superseded records; link the replacing ADR instead of deleting history.
- A decision is accepted only when merged to the default branch.
